《校长我来当》4.2 更新日志

版本：4.2
版本号：35

一、学生生活功能扣款修复
1. 修复学生生活页在资金不足时仍可反复点击升级、维修、扩容并无限扣款的问题。
2. 升级设施、单个维修、一键维修、扩容现在统一为"先校验余额，扣款成功后才提交设施变化"的原子流程。
3. 所有操作增加串行保护，阻止快速连续点击在扣款前重复提交。
4. 资金不足时不再改变设施状态，也不会扣到负资产。

二、其他消费入口统一校验
1. 校区扩建的校区等级升级、建筑维修、建筑质量升级全部改为原子扣款校验，避免余额不足仍可操作。
2. 家长会改为扣款成功后才创建会议，余额不足时不会"免费开会"。
3. 校友活动（聚会、论坛、募捐晚会）改为先校验余额再举办，余额不足时不消耗冷却也不白嫖活动效果。
4. 设施购买、升级、维修原有原子校验保留。

三、进度保存与数据安全
1. 修复数据库瞬时异常时 UI 把"有存档"误判为"无存档"的问题：查询异常不再清空界面状态，主菜单"继续游戏"和顶部年月日不再因为一次临时错误而消失。
2. 应用退到后台时立即落盘一次自动保存，避免进程被系统回收时最新进度停留在内存中。
3. 移除设置页遗留的整局重置入口代码，防止任何隐藏路径误触发全量清档。
4. 继续保留 4.0/4.1 的安全快照、SQLite 完整性校验、原子替换和写入栅栏。

四、兼容说明
1. 版本升级至 4.2（versionCode 35）。
2. 旧存档可直接进入，不会因升级被删除或清空。
3. 自动保存继续固定写入唯一自动存档；旧多存档目录不会被读取、覆盖或删除。
