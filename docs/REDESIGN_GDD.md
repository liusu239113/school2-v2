## 2. 核心循环（学期议程流）

```
开学(9月)          学期中(10-1月)         期末(6月)
┌──────────┐    ┌───────────────┐    ┌──────────────┐
│ 预算分配   │    │ 议程卡逐张处置   │    │ 三轨结算       │
│ 教学/科研/ │ →  │ 人事卡三选一     │ →  │ 学术·财务·民心  │
│ 校园/外联  │    │ 委托/危机/活动   │    │ 排名变动动画    │
│ 4 权重拍板 │    │ 学院流水线拍板   │    │ 下学期开局事件  │
└──────────┘    └───────────────┘    └──────────────┘
      ↑                                   │
      └────────── 排名/评估结果喂回下学期开局 ──┘
```

- **三轨**：学术（排名/科研/升学）、财务（现金流/经费）、民心（学生满意度/教师忠诚）。任何一轨崩 → 危机议程。
- 每学期玩家做 **8~12 次有意义拍板**，单次决策 10~30 秒；一学年 ≈ 15 分钟高密度玩法（对齐"7 天"体量 = 3~4 学年/天）。

## 4. UI 可读性军规（违反即 bug，验收逐条对照）

1. **文字永不压图**：所有正文只出现在实底面板上（白底深字 / 深蓝底白字二选一）。
2. **对比度下限**：正文 ≥ 4.5:1，辅助字 ≥ 3:1；橙黄数字只允许出现在深色底上。
3. **像素字下限 14sp**，标题 18sp+ 并带 1px 深色描边；超过 2 行的说明文字一律折叠进"?"帮助。
4. **教程不再用横条压内容**：改为聚光灯高亮（变暗四周、只亮目标控件）+ 单句气泡。
5. **弹窗重做**：实底白卡 + 青蓝 2px 边 + 左上角标题章（像素印章），底部按钮左右各 50% 宽，价格数字用深底白字胶囊。
6. **横条类贴图禁止拉伸**：九宫格 + 文字必须落在条内实底区（招聘弹窗问题根修）。
7. 每个新页面截图跑一次"3 米测试"：缩小到 1/3 仍能读出所有关键数字。
