# 《校长我来当 2：大学时代》重做方案 GDD v2.0（流程级设计）

> 拍板记录：节奏保留**时间流动**经营；招聘改卡牌三选一；一代美术全部下架换新；
> 核心结构改为**建筑式经营**——自己建楼、点楼进面板、楼内升级与管理。
> 本文档回答"这个游戏到底怎么玩"，从打开 App 到每一天。

---

## 1. 玩家旅程总览（从冷启动到日常循环）

```
打开App
 └─ 主菜单（青蓝夜色大学城 + 3 个按钮）
     ├─ 开始游戏 → 建校向导（3 步）
     ├─ 继续经营（有存档才显示）
     └─ 设置

建校向导
 ├─ 第1步 创校登记：大学名 + 校长名（保留现有输入）
 ├─ 第2步 办学风格三选一：综合型 / 理工强校 / 人文名校（决定开局加成与初始楼）
 └─ 第3步 落成仪式：在校园空地上放下「行政楼」，点燃开学

进入游戏（时间开始流动，节奏与现在一致）
 ├─ 主界面 = 可建造的大学校园（俯视斜45° 像素校园）
 │    ├─ 已建的建筑矗立在校园里，可点击
 │    ├─ 右下角「建造」按钮 → 建造菜单（花钱放新楼）
 │    └─ 底部 4 个 tab：校园 / 治院 / 人事 / 外联
 │
 ├─ 点任意建筑 → 建筑面板（半屏实底卡）
 │    ├─ 楼名 + 等级 + 「升级」按钮（费用/条件/收益）
 │    ├─ 本楼管理区（按楼类型不同，见 §4 建筑表）
 │    └─ 本楼加成摘要
 │
 ├─ 时间流动中：事件以「议程卡」进入右上角议程抽屉（不打断、不弹窗轰炸）
 ├─ 招聘 = 人事区「候选人三选一」卡牌
 └─ 顶部 rival 排名条常驻（青蓝深底白字，永远可读）

日常循环（时间流动版）
  收钱/盯现金流 → 攒经费 → 建新楼或升级旧楼 → 点楼处理该楼管理
  → 处置议程卡（招聘/委托/危机）→ 声誉涨 → 解锁更高等级与更多楼
```

---

## 2. 主菜单（重做）

- 背景：**青蓝夜色大学城横幅**（新绘：远处城市天际线 + 近处大学楼群剪影 + 星空），非一代樱花高中。
- 中央：新青蓝像素徽章 logo + 游戏名（像素字 + 1px 描边）。
- 按钮（≤3 个，实底像素按钮，深底白字）：
  - 「开始游戏」（新档）
  - 「继续经营」（仅有存档时出现，显示当前学年/等级小字）
  - 「设置」
- 禁止：任何文字压浅色装饰条；按钮文字必须落在按钮实底区内。

## 3. 建校向导（重做，3 步）

1. **创校登记**：大学名（4-12 字）+ 校长名（2-6 字）。沿用现有输入，样式换像素实底输入框。
2. **办学风格三选一**（新增，给重开差异化）：
   - 综合型：全学院招生 +4%，起始经费 +50 万
   - 理工强校：理/工学院楼半价，人文招生 −10%
   - 人文名校：人文/艺学院楼半价，理工招生 −10%
3. **落成仪式**：镜头推到校园空地 → 自动放下「行政楼」→ 字幕"2026 年 9 月，大学开学"→ 进入主界面。
- 教学配置（班型）收进行政楼面板，不再开机弹教程长条。

## 4. 建筑总表（旧 20 个功能入口 → 全部收进建筑/分区）

| 建筑 | 解锁 | 升级收益 | 楼内管理面板 |
|------|------|---------|-------------|
| 行政楼 | 初始 | 提升教师上限/经费上限 | 学期预算、政策方针、营销、排行榜、股市(Lv3)、校长办 |
| 人文学院楼 | Lv1·18万 | +招生/+氛围，容量+ | 本学院招生规模、专业（文学/历史/哲学）、师资配置、本学院学生 |
| 理学院楼 | Lv2·36万 | +科研速度 | 专业（数学/物理/化学）、科研课题 |
| 工学院楼 | Lv3·58万 | +就业率 | 专业（计算机/机械/土木）、校企合作委托 |
| 商学院楼 | Lv4·72万 | +声誉 | 专业（金融/管理/营销）、产业合作 |
| 艺术学院楼 | Lv3·65万 | +满意度 | 专业（美术/音乐/设计）、汇演 |
| 医学院楼 | Lv4·110万 | +就业/+声誉 | 专业（临床/护理/药学）、附属医院开关 |
| 图书馆 | Lv1·30万 | 全校科研加速 | 课题链启动/进度 |
| 宿舍 | Lv1·25万 | 学生上限+ | 宿舍满意度、奖学金 |
| 食堂 | Lv1·25万 | 满意度+ | 餐标、生活费 |
| 体育馆 | Lv2·40万 | 体育声誉 | 运动会、社团活动 |
| 就业中心 | Lv2·45万 | 就业率+ | 就业出口、校友网络 |
| 会议中心 | Lv3·60万 | 学术声誉 | 学术会议、校际竞赛报名 |
| 医院病房 | 医学院Lv2 | 诊疗收入 | 实习事件、诊疗收入 |

- **建造规则**：校园是横向展开的地块带（Lv1 开放 4 块地，每升 1 级 +2 块）；点空地 → 建造菜单（按解锁/费用列出）；建造/升级即时扣费，楼体贴图随等级变化（1 级小楼 → 3 级带校徽大门）。
- 旧宫格 20 入口 → 上表 + 治院/人事/外联 3 个 tab，**无一遗漏，无一重复**。

## 5. 四个底部 tab（二级页面，全部实底重做）

- **校园**：回到剖面视图（默认）。
- **治院**：学期预算（4 权重条）、年度方针、评估报告、财务报表（替代一代报表页）。
- **人事**：候选人三选一卡牌（主入口）、教师名录、学生名册。
- **外联**：大学排名榜（含 rival 对比）、竞赛、社会委托板、校友动态。

## 6. 招聘（卡牌化，按拍板执行）

- 进入人事 tab → 「本学期候选人」：亮 3 张卡（姓名/科目/等级/特质/诉求薪资/风险）。
- 选 1 弃 2；每学期免费刷新 1 次，二次刷新花经费。
- 渠道概念收进治院「招聘预算」滑杆：预算高 → 高等级卡概率高。
- 卡面：实底白卡 + 青蓝边 + 顶部科别色条；所有数字深底白字胶囊。

## 7. UI 可读性军规（沿用 v1.0，验收逐条对照）

1. 文字永不压图；2. 对比度下限 4.5:1；3. 像素字 ≥14sp、标题带描边；4. 教程用聚光灯高亮，禁止横条压内容；
5. 弹窗/面板实底白卡；6. 横条贴图必须九宫格且文字落实底区；7. 每页过"缩到 1/3 仍可读"测试。

## 8. 美术套图清单（M1 全部新绘，逐张目检像素质感）

1. 主菜单：青蓝夜色大学城横幅 16:9
2. 校园基底：俯视斜45° 草地/道路/地块格（可平铺）
3. 建筑贴图第一批（各 2 级状态）：行政楼、人文楼、理学院楼、图书馆、宿舍
4. 建造菜单图标：锤子/地块
5. 议程卡框（普通/紧急）、候选人卡框
6. logo 徽章（青蓝版，替换紫金一代）
- 下架：一代樱花高中全部背景、紫金 logo、所有旧宫格入口图。

## 9. 里程碑

- **M1（本阶段）**：主菜单 → 建校向导 → 建筑式校园（建造/点楼/升级）→ 人事三选一 → 治院预算 → 时间流动照旧。一代 UI 全部隐藏。真机验收。
- **M2**：剩余建筑面板（科研/就业/会议/医院）、外联排名榜、委托板、竞赛。
- **M3**：全套背景/楼体 2-3 级贴图、动效音效、文案清洗、7 天内容灌入。

## 10. 底层复用声明

GameEngine 时间流动、月结/学年结算、经济数值、学院/专业/师资覆盖、竞赛、课题链、成就、存档——全部保留为无头逻辑；重做的只有呈现层（导航/页面/面板/美术/文案）。「建楼」映射现有数据：学院楼=学院成立，功能楼=原设施系统，楼等级=原设施等级/学院加成，不新增数据库迁移。
