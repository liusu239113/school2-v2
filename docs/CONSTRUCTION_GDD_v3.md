## 1. 全局 UI 修复细则

1. `TopResourceBar`（新公共组件）：高 48dp 实底深藏青，三段白字（经费/声誉/校园等级），四主区统一置顶；删除旧 PixelInfoBar 及其横条图引用。
2. 像素按钮规范：亮色系按钮图（primary 白冰/secondary 白）→ 文字深藏青；深色系（青蓝/红/绿）→ 白字。主菜单、建造菜单、面板按钮统一套用。
3. 楼名标签：位于楼图**正下方 2dp**、紧贴，宽度不超楼宽；不再遮挡任何建筑像素。
4. 反馈位置规范：
   - 建造菜单内操作 → 菜单顶部消息条（自动 3 秒消失）
   - 建筑面板内操作 → 面板顶部消息条
   - 全局消息条仅保留给无上下文的系统事件，位置固定在资源条正下方，不压地图中心。
5. 弹窗（事件/故事）文字区加实底白色衬底（当前半透明压地图导致对比不足）。

## 2. 瓦片自由建造系统（新核心玩法）

### 2.1 地图与网格
- 地图 **22 × 14 格**，每格 48dp；初始解锁中央 **14 × 8**，校园每升 1 级向外扩一圈（Lv6 全图）。
- 摄像机：单指拖动平移（限制在地图范围），双击回中；不需要缩放。
- 未解锁区域：压深色半透明+锁链纹理，不可交互。

### 2.4 建造交互流
1. 建造菜单（底部抽屉）选建筑/瓦片/装扮 → 进入**摆放模式**。
2. 摆放模式：选中物半透明跟随手指所在格；合法位绿框、非法位红框（道路格与已占格非法；装扮可放路旁）。
3. 点 ✓ 落地扣费（资金不足在**菜单内消息条**提示），✕ 退出。
4. 已建建筑：点开面板 → 「搬移」（进入同款摆放模式，免费）/「拆除」（返 30%）。
5. 初始布局：行政楼固定中上；首次进入把已有设施自动摆到默认空位（可搬移）。
6. 存档：`policyJson` 内新增 `buildings: [{kind,type,x,y,level}]`，旧档迁移自动落位。

### 2.5 楼体升级可视化
升级后楼贴图加**像素特效层**（Lv2 加门灯、Lv3 加旗子/徽章光点），不再换图，成本可控。
