《校长我来当》3.8 更新日志

版本：3.8
版本号：30

一、成就系统
1. 移除“开设课程”相关旧成就，避免展示当前版本无法完成的历史玩法条件。
2. 移除分校和自主研发教学技术相关旧成就，避免出现不可达成或无入口的成就。
3. 将教材成就调整为当前学校发展和设施建设条件。
4. 将名师摇篮成就调整为当前学校等级与教师容量条件。
5. 成就分类筛选补充“师资”和“设施”分类，方便查找对应成就。
6. 老存档中已保存的历史成就解锁记录仍保持兼容；已移除的历史成就不再计入当前成就总数。

二、学生与班级
1. 修复班级管理顶部年级筛选在小屏幕上横向被裁剪的问题。
2. 高一、高二、高三筛选项支持横向滚动，第三个年级不会因屏幕宽度不足而隐藏。
3. 保留现有班级按年级分组、学生人数统计和班主任分配逻辑。

三、教师系统
1. 修复S级教师首次进入教师发展系统时，因技能阈值判断被错误降为A级的问题。
2. 教师发展档案同步时以主系统教师等级为最低等级，不再反向覆盖造成降级。
3. 修复教师等级、教师发展职称和培训技能之间的同步问题，培训增益不会被每月同步抹掉。
4. 修复教师离职后仍可能生成合同续约事件的问题。
5. 修复同一名教师合同到期后续约弹窗重复生成的问题；玩家处理前只保留一次待处理续约事件。
6. 新游戏、读档和历史教师数据继续兼容，教师发展数据缺失时按当前教师等级安全初始化。

四、设施维护
1. 保留并确认学区设施“一键维修”入口可用。
2. 一键维修会一次性计算全部待维修设施费用，并在资金不足时阻止部分扣款。
3. 单项维修和一键维修均使用学校数据原子更新，避免余额与设施状态不同步。

五、存档与合规版本
1. 本版本为正常 TapTap 登录与防沉迷版本，不是7723临时渠道包。
2. 保留此前多存档直接读档、当前活动档位和向下兼容修复。
3. 版本号升级至3.8（versionCode 30）。

六、构建结果
1. Android Release APK 构建成功。
2. Build & Release APK 构建成功。
3. 发布附件配额已满，因此工作流跳过额外 Artifact 上传；APK 已正常生成并发布到 GitHub Release。
