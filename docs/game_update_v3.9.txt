《校长我来当》3.9 更新日志

版本：3.9
版本号：31

一、升学就业与历史毕业生
1. 修复发展多年后“升学就业仍为0 / 毕业多年仍显示大学在读”的问题。
2. 历史毕业生补录改为幂等注册，不再因就业数据为空而把旧毕业生重置为大学第0个月。
3. 按毕业年月与当前游戏日期校准大学进度；已超过学制者立即结业并生成稳定职业结果。
4. 读档时自动去重、校准并回写 employmentJson，避免错误状态被长期固化。

二、派系事件
1. 修正“教师集体不满”文案：不再无依据指责“重行政轻教学”。
2. 同一派系不满事件增加冷却，降低每月重复刷出。
3. 派系事件改为可选事件（ChoiceEvent），“安抚 / 置之不理”等选项可真实生效。
4. 选项关系变化幂等结算，同一事件不会重复加减关系。

三、考试分数
1. 语文、数学、英语满分调整为150，其余科目保持100。
2. 学业指数、排名、趋势统一按0-100得分率计算，避免主科被1.5倍放大。
3. 旧考试存档无满分版本时按旧100分制兼容恢复。
4. 高考历史稳定性加成改为使用归一化得分率。
5. 学生详情单科显示为“128 / 150”，平均显示为得分率。

四、课表与班主任
1. 全校统一排课，同一教师同一时段不可跨班冲突。
2. 同科教师按当前课时与班主任负担均衡分配，不再总是选第一位教师。
3. 任命/撤销/一键分配班主任后立即刷新全校课表。
4. 毕业空班删除时同步清理课表缓存。

五、教师离职链路
1. 离职、辞职、挖角、合同到期等事件展示“姓名（任教科目）”。
2. 批准离职、不续约、倦怠离职后统一刷新课表。
3. 通知中心将“辞职/离职”正确归类为教师类高优先级通知。
4. 教师发展离职在同名情况下增加日志保护，减少误删风险。

六、版本与兼容
1. 版本号升级至3.9（versionCode 31）。
2. 本版本为正常 TapTap 登录与防沉迷版本。
3. 旧存档向下兼容；就业、考试、课表关键修复会在读档时自动迁移/校准。
