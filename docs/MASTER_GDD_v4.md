# 《校长我来当 2：大学时代》总体框架方案（Master GDD v4）

> 性质：**整个游戏的总框架**，覆盖全部系统、全部页面、全部残留。基于 2026-08-29 代码全量盘点（32 个 domain 系统、34 个页面）写成。
> 流程：本方案确认 → 按分期实施 → 每期一次构建。

---

## 一、游戏是什么（一句话 + 三支柱）

你是一所 2026 年新建的中国应用型本科大学的校长。**时间自由流动**，你用有限的经费和声誉，在 22×14 的校园里建楼、设学院、聘教师、招学生，把一所三流学院办成世界一流大学。

**三大体验支柱**（所有系统必须服务其一，不服务就删）：
1. **建设** —— 校园是我一块块建出来的（瓦片建造/装扮/升级可视化）
2. **治理** —— 每一笔预算、每一个方针都是取舍（预算/政策/评估/排名）
3. **育人** —— 招生→培养→就业的完整人才流水线，学生和教师是可见的人（头像/名字/成长）

## 三、系统集成图（数据流矩阵）

```
                    ┌─────────────── 时间流动 (GameEngine tick) ───────────────┐
                    │                                                          │
 报考大类计划 ──→ 9月招生 ──→ 大一(大类) ──学年──→ 大二分专业 ──→ 大三/大四 ──→ 毕业评估
     ↑              │            │              │                │            │
     │          教室容量(CourseScale)   学院师资覆盖 ──→ 掌握度/毕业分    │        就业/深造
 政策·营销·声誉 ──┘            │              │                             │        → 行业/薪资
                              │              ├──→ 校际竞赛(胜负) ──→ 排名榜 │
 学期预算(10点) ─→ 教学/科研/生活/社会 四轨 ──┘   课题链(科研日) ──→ 学术声誉   │
                                                                        ↓
 建造(建筑/瓦片/装扮) ──→ 容量/满意度/科研加速 ────────────────→ 三轨结算 → 评估 → 等级晋升
 (装扮→满意度微调；宿舍→容量；图书馆→科研日)
```

**集成规则**（新功能准入测试）：任何新系统必须回答"它读谁的数据、喂谁的数值"，答不出就不准进。

## 四、玩家旅程（分钟级）

| 阶段 | 玩家操作 | 时长 |
|------|---------|------|
| 冷启动 | 隐私→主菜单→建校三步（名/风格/确认） | 2 分钟 |
| 第 1 学年 | 教学配置容量 → 建人文楼+图书馆+宿舍 → 招聘三选一×2 → 首批 80~110 名学生入学 → 处置事件卡 → 6 月毕业评估+学年考核 | 20~30 分钟 |
| 第 2~3 学年 | 升 Lv2 → 建理学院 → 大二分专业 → 竞赛首战 → 师资补缺 → 附属医院/硕博点筹备 | 每学年 15~20 分钟 |
| 第 4~6 学年 | Lv3~4：工/艺/商学院齐备 → 全国赛 → 排名爬升 → 捐赠/会议长线 | 同上 |
| 长线 | Lv5~6：硕博点产出、装扮校园、成就全收集、世界第一 | 自由 |

## 八、办学类型系统（v4.1 已实施）

> 建校流程升级为四步：①登记 → ②**办学层次** → ③**办学性质** → ④办学风格 → 确认。

### 8.1 办学层次（SchoolTier，`domain/model/UniversityType.kt`）
| 层次 | 学制 | 分数线 | 学费系数 | 招生规模 | 生源质量 | 启动经费 | 可设学院 | 长线目标 |
|------|------|--------|---------|---------|---------|---------|---------|---------|
| 高职专科 VOCATIONAL | 3 年（毕业=大三6月） | 320~430 | ×0.6 | ×1.35 | ×0.8 | 380 万 | 人文/工学/商学 | **升格职业本科**：声誉≥1000 · 校园≥2级 · 经费≥200万 · 在校生≥200人（月结达标自动触发 MilestoneEvent） |
| 应用型本科 APPLIED | 4 年（现状基准） | 430~520 | ×1.0 | ×1.0 | ×1.0 | 500 万 | 六学院全开 | 世界一流大学（现有里程碑体系） |

- 学制分化：`isStudentGraduationDue` / `ClassManager.yearEndPromotion` / `conductGaoKao` / 毕业年级事件全部按 `tier.graduationGrade` 分派；专科永远不会出现大四学生。
- 学院限制：`GameEngine.foundCollege` 拒绝专科目录外学院；办学风格赠送学院若不在目录内折算为等额开办经费（`applyFoundingStyle(key, allowedColleges)`）。
- 升格后：`tierKey→APPLIED`，四年制/全学院即刻生效，存量大三学生按新规则自然升入大四。

### 8.2 办学性质（SchoolOwnership）
| 性质 | 学费 | 财政拨款 | 招生 | 评估补贴 |
|------|------|---------|------|---------|
| 公办 PUBLIC | ×0.75（受管制） | **0.12 万/生/月**按月拨付（月结内，重试不重复发） | ×1.08 | ×1.2 |
| 民办 PRIVATE | ×1.15（自主） | 0 | ×1.0 | ×0.6 |

### 8.3 持久化与兼容
- `tierKey`/`ownershipKey` 走 `school_manager_states` 键值表（`SchoolManagerStateKeys.TIER_KEY/OWNERSHIP_KEY`），**不动 Room schema、无需迁移**。
- 旧档缺省 = 应用型本科 + 民办（与旧行为等价）。
- 主菜单存档摘要显示「名称 · 层次·性质 · Lv · 日期」。

### 8.4 系统联通（v4.2 已实施）
- **毕业评估**：`graduateScoreFactor`（专科 ×0.85）接入 `conductGaoKao`，专科深造去向自然减少、就业去向为主。
- **招生录取线**：`admissionScoreMin/Max` 分数带 × 声誉热度 → 「新学年开学」事件显示当年录取线与办学类型。
- **专科就业率生命线**：月结检查就业率 <55% → 教育厅整改通报（声誉-8），回升自动解除。
- **公办财政兜底**：公办破产线放宽至 3×BANKRUPTCY_THRESHOLD（-150 万），民办维持 -50 万。
- **主界面**：顶栏日期行显示「层次·性质」徽标（升本后自动更新）。

### 8.5 类型深化（v4.3 已实施）
- **研究型大学（RESEARCH）**：第 3 种层次——学费 ×0.7、招生 ×0.75 但生源 ×1.25、启动 650 万、毕业评估 ×1.15；**科研经费按月到账**（已解锁科研方法 × 0.45 万/月）；硕博点校园 3 级即可启动（其他层次 5 级）。
- **公办薪酬编制**：公办校长月薪由财政代发（从拨款净额扣除），不占用学校经费；民办照旧自付。
- **GameOver 结算页**：经营记录新增「办学类型」一行（层次·性质）。

### 8.6 玩法闭环（v4.4 已实施）
- **职业本科（VOCATIONAL_BACHELOR）独立层次**：专升本的升格目标——4年制、学费×0.85、校企合作（就业辅导费6折、就业声誉+50%）、人文/工学/商学/艺术四学院、毕业评估×0.95。
- **升格手动申报制**：条件达标后月结发出「升格申报：省教育厅来函」ChoiceEvent，校长签字申报或暂缓（当年冷却）；经 `EventConsequence.promotionAction` → `GameEngine.executePromotionApproval` 幂等执行。
- **竞争组别**：竞赛奖励按层次分化——研究型（奖金×0.8、声誉×1.3）、职业类（奖金×1.15、声誉×0.9）、应用本科（标准）。

### 8.7 后续扩展（未实施）
- 职业本科→应用型本科二次升格；研究型独立对手池；GameOver 页显示升格史。
